## DarkCipher MaskedMail 0.3.0 (2026-10-20)

**Every masked-email and throwaway service that could be integrated securely.** There are now thirteen services in
three kinds, each with everything its API allows. Settings has a page for each kind, and the app only ever offers
what a service really supports.

- **Masked-email services:**
  - **SimpleLogin** (your **Proton Pass** aliases are SimpleLogin aliases, so they appear too) now also lets you pick
    the suffix and the mailbox, and shows each alias's recent **activity**.
  - **addy.io** now lets you pick the domain, the recipient and the name style (random characters, UUID, words, names,
    nouns).
  - **Firefox Relay** is unchanged.
  - **New: DuckDuckGo** (@duck.com). Only creating is possible: DuckDuckGo has no public API, and this uses the call
    its own extension makes (password managers do the same). Settings flags it as unofficial. The app keeps its own
    encrypted list of the addresses it made.
- **New: your own domains:**
  - **Forward Email:** list, create, note, turn off (drop, bounce or defer), delete, and **send** through Forward
    Email itself.
  - **Cloudflare Email Routing:** free addresses as routing rules to a verified destination. Settings asks for a token
    scoped to Email Routing only.
  - **ImprovMX:** list, create, delete, and each address's delivery log.
  - **Migadu:** aliases for a Migadu mailbox on the same domain.
  - **mailcow** (your own server): ordinary aliases, plus **time-limited aliases that the server deletes by itself**.
    These are used for throwaways, so they end even if the app never runs again.
- **New: disposable inboxes,** read right in the app. They are **off until you tick them**, after a caution that the
  service can read the mail.
  - **Mail.tm / Mail.gw:** read, mark, delete, save attachments, delete the inbox.
  - **TempMail.lol:** ends by itself after about an hour.
  - **DropMail:** ends about 10 minutes after the last check; needs a free token.
- **Throwaways on any service:**
  - they end in the strongest way that service has: deleted or turned off, a server-side time limit, or the
    service's own lifetime;
  - a lifetime the service can't keep is capped, and "+1 hour" is hidden where it can't work;
  - when a service can only forget an address (DuckDuckGo), the app says so plainly, and the security log records
    what was done.
- **New address form:** only shows what the chosen service can do (a chosen name, domain, where mail goes), and shows
  its caution before anything is created. The address card does the same (Activity, Remove from list…).
- **Left out on purpose,** with the reason shown in Settings:
  - public inboxes anyone can read by guessing the address (Guerrilla Mail, Maildrop, Mailinator, Mailsac);
  - Guerrilla Mail's plain-HTTP API;
  - services without a public, documented API (iCloud Hide My Email, TrashMail.com, 33mail and others).
- **Security:**
  - every service goes through the same hardened HTTPS client: no redirects, TLS 1.2+, answers capped at 16 MB;
  - a link a service hands back is only fetched on that service's own host, so a token can't be sent elsewhere;
  - self-hosted servers must be https://;
  - every key, token and inbox password is encrypted with the rest of the settings;
  - add-on approvals now show the service's caution.
- **Code:** four new small projects:
  - `DcxMail.Providers` (what every service shares);
  - `.Masked`, `.Domains` and `.Disposable`, with one plain file per service.

  Each service describes itself (`ServiceInfo`), and Settings builds its card from that. Adding a service is one
  file plus one catalog line. Unit tests: 127, up from 77, including one per service checking that what it declares
  matches what it implements.
- **Your settings carry over:** the SimpleLogin, addy.io and Firefox Relay keys from 0.2 move into the new service list
  on first start.
- **Not yet tried against real accounts:** the new services were built from their documented APIs and tested against
  fakes that answer the same way.

## DarkCipher MaskedMail 0.2.0 (2026-10-20)

A stability and code-quality release. Your settings, keys and add-ons carry over unchanged, and nothing about how the
app looks or works has changed, apart from the fixes below.

- **Smaller projects.** The single app project is now a solution of focused projects, with references that only point
  one way:
  - `DcxMail.Core`: storage and security;
  - `DcxMail.Mail`: Fastmail JMAP and the HTML tools;
  - `DcxMail.Aliases`: the four services, throwaways and the queue;
  - `DcxMail.Addons`: the sandbox and bridge, now with no UI code in it;
  - `DcxMail.Fakes`: the test servers;
  - the WPF app;
  - the tests.
- **Real unit tests.** The logic checks moved out of the exe into an xUnit project: 77 tests, including real sandboxed
  add-on runs. The exe's `--selftest` now covers only what needs the real app (renders, capture guard, Settings
  search, editor policy, clipboard, DLL policy). The build runs both and stops on any failure.
- **Stricter build gates.** Every project builds with:
  - the .NET analyzers, every security rule on, warnings as errors;
  - a NuGet vulnerability audit of every package, direct and transitive;
  - locked package versions, pinned in one place.

  The analyzers found nothing exploitable. Every P/Invoke now loads its Windows DLL from System32 only.
- **Errors are logged.** Unexpected errors from any thread now go to a new encrypted `errors.log`, so a problem can
  be diagnosed afterwards. Before, a background-thread error left no trace.
  - A UI error still shows a message and the app keeps running.
  - The same error repeating within 10 seconds is no longer shown again, so a failing timer can't stack up dialogs.
- **Faster routing.** The 30-second routing sweep only fetches your folder list when it has mail to move. A quiet
  sweep is now one request instead of two, and a folder you deleted in Fastmail is still never used.
- **Safer throwaway clean-up.** When a throwaway ends, its folder is emptied and removed only if it still has the
  throwaway's name. If you renamed the folder to keep it, it's left alone, with its mail.
- **The add-on SDK is no longer embedded in the app.** Only the tests need it. The exe stays about the same size, since
  the split adds a few small assemblies.

## DarkCipher MaskedMail 0.1.6 (2026-10-19)

**Security hardening release.** The full report is in [SECURITY-AUDIT-0.1.6.md](SECURITY-AUDIT-0.1.6.md).

- **Composer.** Quoted mail can no longer run script in the composer.
  - The editor runs only its own script, using a random nonce for each load.
  - Quoted HTML is cleaned by an inert DOM sanitizer as well as a much stronger server-side one. That one now catches
    `/`-separated handlers, svg, srcdoc, formaction and entity-encoded `javascript:`.
- **Network.**
  - Redirects are never followed, so an API key can't be carried to another host.
  - Only HTTPS with TLS 1.2/1.3 is used.
  - Fastmail's session URLs must be HTTPS before the token is sent.
- **Message viewer and editor.** Permission requests and downloads are denied. Swipe navigation, script dialogs and
  certificate-error pages are off.
- **Folders.** The data and cache folders are locked to your Windows account (and SYSTEM).
- **Security log.** It is hash-chained, so removed or reordered entries show as "⚠ log altered".
- **Sign-in.**
  - Wrong passwords and codes are counted across restarts, with an increasing wait.
  - Password-derived keys are wiped from memory after use.
  - Master and backup passwords must be stronger: 12+ characters, not common, and mixed (or a 16+ character
    passphrase).
- **Screen capture.** The sign-in screen, 2FA set-up, recovery codes and password prompts never appear in screenshots,
  recordings or streams. A new option hides every MaskedMail window from capture.
- **Recovery codes** copied to the clipboard are cleared after 60 seconds.
- **Replying.** Quoting a message no longer loads its remote images, so tracking pixels don't fire.
- **Process mitigations.** No DLLs from network locations or with a Low integrity label, no DLL search in the current
  directory, and the process terminates on heap corruption.
- **New documentation:** a user guide, the security model, the security audit report, architecture and testing.
  They are included in the release folder.
- **Self-test: 44 checks**, 9 more than 0.1.5.

## DarkCipher MaskedMail 0.1.3 (2026-10-19)

The security options now match DarkCipher ServerManagement's. Everything is under **Settings → Security & encryption**.

- **Master password.** The data key can be wrapped by a master password (PBKDF2-SHA256, 600,000 iterations) as well as
  by your Windows account. With "require at start" turned on, the Windows-account copy of the key is removed. Nothing
  can then be decrypted without the password, not even by an administrator or from a copy of the disk.
- **Two-factor sign-in.** Works with any authenticator app: Microsoft, Google, Authy, 1Password, Bitwarden and others.
  - Set it up from a QR code (RFC 6238 TOTP).
  - Codes cannot be replayed.
  - You get 10 recovery codes, and each works once. They are stored only as hashes, and the authenticator secret is
    encrypted.
- **App lock.**
  - Locks automatically after a period of inactivity.
  - Locks when Windows locks or the PC sleeps.
  - **Lock now** button (🔒) in the header, Ctrl+Shift+L, or from the tray.
  - If MaskedMail is only in the tray, the lock takes effect the next time a window opens.
  - Mail keeps being filed while the app is locked.
- **Sandbox mode.** The master password is required at every start, auto-lock is always on, and the message viewer's
  browser cache is wiped on exit.
- **Encrypted backup / restore** (`.dcxbackup`). It holds every API key and setting, sealed with a password of its own,
  so it can be restored on any PC.
- **Security log.** It records sign-ins, locks, security changes, backups, and masked addresses created, enabled,
  disabled or deleted. Each line is encrypted. It never contains keys, passwords or message content.
- **No message content on disk.** Large messages used to be written to a temporary `reader.html` file in plain text.
  They are now served to the viewer from memory, and any leftover file from 0.1.0–0.1.2 is deleted at start.
- **Safer start-up.** If the settings file ever fails to decrypt, the app stops with an error instead of starting with
  empty settings, which would have overwritten the file.
- **Upgrade.** The key from 0.1.0–0.1.2 moves into the new key ring unchanged, so existing settings keep working.
- **Fixed:** a restored backup could match folder addresses case-sensitively.
- The self-test grew from 23 to 30 checks, including the RFC 6238 test vectors, and now renders the sign-in screen too.

## DarkCipher MaskedMail 0.1.0 (2026-10-19)

This is the first release.

- **Masked addresses.** Create, edit, enable, disable and delete masked addresses. Four services are supported:
  - Fastmail Masked Email (JMAP)
  - SimpleLogin
  - addy.io
  - Firefox Relay

  Aliases from all of them appear in one list, with search and filters by service and by state.
- **Folders and routing.** Each new address gets `Inbox/automation/<address>`. Inbox mail sent to the address is moved
  there on a timer (2 min by default). The app keeps doing this while it sits in the notification area, and it can
  start with Windows.
- **Mail client.**
  - Inbox, Sent and a view of each address's folder.
  - Reader: scripts are off, remote images are blocked until you load them, and attachments can be saved.
  - Reply, reply all, forward, mark unread, and delete (moves the mail to Trash).
- **Composer.**
  - HTML formatting: fonts, sizes, colours, lists, alignment, links and quotes.
  - Images can be inserted, pasted or dragged in. They are sent as inline parts.
  - Attachments.
  - Sending from a masked address. Fastmail sends directly; SimpleLogin and addy.io go through a reverse alias.
- **Security.** Settings and API keys are encrypted with AES-256-GCM, and the key is protected by DPAPI.
- **Self-test.** `--selftest` runs 23 checks against fake servers and draws every window off-screen.

**Not yet tried against real accounts.** Everything has been checked against in-process fakes only.
