# DarkCipher MaskedMail 0.3.4 (2026-10-21)

- **Release tooling:** a personal name had slipped into comments in the release scripts and `docs/RELEASING.md`; they
  now say "the owner". The pre-publish privacy scan now checks every term the website's own publishing gate checks, so
  that can't happen again.
- **Release pipeline:** each release now writes a manifest of exactly what the website publishes (`release-manifest.json`:
  every file with its SHA-256 and the GitHub Release asset it must equal). After the website is deployed, the pipeline
  downloads each file from darkciphersystems.com and compares it byte for byte, and it records the Discord announcement.
- No change to the app itself since 0.3.2.
