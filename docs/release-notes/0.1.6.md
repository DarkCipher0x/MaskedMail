# DarkCipher MaskedMail 0.1.6 (2026-10-19)

**Security hardening release.** The full report is in [SECURITY-AUDIT-0.1.6.md](../SECURITY-AUDIT-0.1.6.md).

- **Composer.** Quoted mail can no longer run script in the composer.
  - The editor runs only its own script, using a random nonce for each load.
  - Quoted HTML is cleaned by an inert DOM sanitizer as well as a much stronger server-side one. That one now catches
    `/`-separated handlers, svg, srcdoc, formaction and entity-encoded `javascript:`.
- **Network.**
  - Redirects are never followed, so an API key can't be carried to another host.
  - Only HTTPS with TLS 1.2/1.3 is used.
  - Fastmail's session URLs must be HTTPS before the token is sent.
- **Message viewer and editor.** Permission requests and downloads are denied. Swipe navigation, script dialogs and
  certificate-error pages are off.
- **Folders.** The data and cache folders are locked to your Windows account (and SYSTEM).
- **Security log.** It is hash-chained, so removed or reordered entries show as "⚠ log altered".
- **Sign-in.**
  - Wrong passwords and codes are counted across restarts, with an increasing wait.
  - Password-derived keys are wiped from memory after use.
  - Master and backup passwords must be stronger: 12+ characters, not common, and mixed (or a 16+ character
    passphrase).
- **Screen capture.** The sign-in screen, 2FA set-up, recovery codes and password prompts never appear in screenshots,
  recordings or streams. A new option hides every MaskedMail window from capture.
- **Recovery codes** copied to the clipboard are cleared after 60 seconds.
- **Replying.** Quoting a message no longer loads its remote images, so tracking pixels don't fire.
- **Process mitigations.** No DLLs from network locations or with a Low integrity label, no DLL search in the current
  directory, and the process terminates on heap corruption.
- **New documentation:** a user guide, the security model, the security audit report, architecture and testing.
  They are included in the release folder.
- **Self-test: 44 checks**, 9 more than 0.1.5.
