# DarkCipher MaskedMail 0.3.3 (2026-10-21)

- **MaskedMail is public:** the source is on GitHub (github.com/DarkCipher0x/MaskedMail) and the downloads are on
  darkciphersystems.com. Both carry the same files with the same SHA-256 checksums.
- **One release pipeline** (`release.ps1`, [docs/RELEASING.md](../RELEASING.md)). Every published file comes from one
  privacy-scanned source zip:
  - an allowlist decides what may be published, and a new file stops the build until it is classified;
  - every image is approved by a person;
  - gitleaks runs alongside the privacy scan, with rules for Discord webhooks and every GitHub and Fastmail token format;
  - each step checks it is publishing where it should, never force-pushes, never changes a published version, and can
    be safely run again;
  - a kill switch (`DCX_PUBLISH_OFF`) holds every public step.
- **README:** links to the website download, the latest release, the user guide, security and what's new.
- No change to the app itself since 0.3.2.
