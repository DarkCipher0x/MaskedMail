# DarkCipher MaskedMail 0.3.0 (2026-10-20)

**Every masked-email and throwaway service that could be integrated securely.** There are now thirteen services in
three kinds, each with everything its API allows. Settings has a page for each kind, and the app only ever offers
what a service really supports.

- **Masked-email services:**
  - **SimpleLogin** (your **Proton Pass** aliases are SimpleLogin aliases, so they appear too) now also lets you pick
    the suffix and the mailbox, and shows each alias's recent **activity**.
  - **addy.io** now lets you pick the domain, the recipient and the name style (random characters, UUID, words, names,
    nouns).
  - **Firefox Relay** is unchanged.
  - **New: DuckDuckGo** (@duck.com). Only creating is possible: DuckDuckGo has no public API, and this uses the call
    its own extension makes (password managers do the same). Settings flags it as unofficial. The app keeps its own
    encrypted list of the addresses it made.
- **New: your own domains:**
  - **Forward Email:** list, create, note, turn off (drop, bounce or defer), delete, and **send** through Forward
    Email itself.
  - **Cloudflare Email Routing:** free addresses as routing rules to a verified destination. Settings asks for a token
    scoped to Email Routing only.
  - **ImprovMX:** list, create, delete, and each address's delivery log.
  - **Migadu:** aliases for a Migadu mailbox on the same domain.
  - **mailcow** (your own server): ordinary aliases, plus **time-limited aliases that the server deletes by itself**.
    These are used for throwaways, so they end even if the app never runs again.
- **New: disposable inboxes,** read right in the app. They are **off until you tick them**, after a caution that the
  service can read the mail.
  - **Mail.tm / Mail.gw:** read, mark, delete, save attachments, delete the inbox.
  - **TempMail.lol:** ends by itself after about an hour.
  - **DropMail:** ends about 10 minutes after the last check; needs a free token.
- **Throwaways on any service:**
  - they end in the strongest way that service has: deleted or turned off, a server-side time limit, or the
    service's own lifetime;
  - a lifetime the service can't keep is capped, and "+1 hour" is hidden where it can't work;
  - when a service can only forget an address (DuckDuckGo), the app says so plainly, and the security log records
    what was done.
- **New address form:** only shows what the chosen service can do (a chosen name, domain, where mail goes), and shows
  its caution before anything is created. The address card does the same (Activity, Remove from list…).
- **Left out on purpose,** with the reason shown in Settings:
  - public inboxes anyone can read by guessing the address (Guerrilla Mail, Maildrop, Mailinator, Mailsac);
  - Guerrilla Mail's plain-HTTP API;
  - services without a public, documented API (iCloud Hide My Email, TrashMail.com, 33mail and others).
- **Security:**
  - every service goes through the same hardened HTTPS client: no redirects, TLS 1.2+, answers capped at 16 MB;
  - a link a service hands back is only fetched on that service's own host, so a token can't be sent elsewhere;
  - self-hosted servers must be https://;
  - every key, token and inbox password is encrypted with the rest of the settings;
  - add-on approvals now show the service's caution.
- **Code:** four new small projects:
  - `DcxMail.Providers` (what every service shares);
  - `.Masked`, `.Domains` and `.Disposable`, with one plain file per service.

  Each service describes itself (`ServiceInfo`), and Settings builds its card from that. Adding a service is one
  file plus one catalog line. Unit tests: 127, up from 77, including one per service checking that what it declares
  matches what it implements.
- **Your settings carry over:** the SimpleLogin, addy.io and Firefox Relay keys from 0.2 move into the new service list
  on first start.
- **Not yet tried against real accounts:** the new services were built from their documented APIs and tested against
  fakes that answer the same way.
