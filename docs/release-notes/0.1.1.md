# DarkCipher MaskedMail 0.1.1 (2026-10-19)

- **Windows installer (MSI).** It works the same way as DarkCipher ServerManagement's installer.
  - **Installs to** `C:\Program Files\DarkCipher Systems\MaskedMail`.
  - **Shortcuts:** a Start menu shortcut, an optional desktop shortcut, and a "Repair or uninstall" shortcut.
  - **WebView2:** the installer offers the WebView2 Runtime through winget, ticked only when it is missing.
  - **Upgrades:** later versions upgrade in place and keep your keys and settings.
  - **Uninstall:** asks whether to delete your encrypted settings and the cache; nothing is deleted unless you tick
    it. The start-with-Windows entry is always removed.
- **A copy running in the notification area is closed first.** The installer does this before it upgrades, repairs
  or uninstalls (new `--exit` switch). Unsent drafts are not prompted for in that case.
- **Taskbar grouping.** The taskbar groups the window with the Start menu shortcut (AppUserModelID).
