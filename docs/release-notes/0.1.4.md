# DarkCipher MaskedMail 0.1.4 (2026-10-19)

- **New icon.** A masquerade mask over an envelope, inside the DarkCipher teal ring. It is used for the app, the
  taskbar, the installer and the header. `tools\make-icon.ps1` draws it.
- **Settings redesigned like ServerManagement.**
  - Categories on the left, with **Security & privacy** first.
  - A search box that finds any option (Ctrl+F).
  - One category at a time, laid out as cards.
- **Security is easy to find.**
  - The 🔒 header button locks the app. If no lock is set up yet, it takes you to Security.
  - The status bar shows the encryption state ("encrypted · password · 2FA · lock 15m"). Click it to open Security.
- **Outgoing queue (📤 Queue, Ctrl+Shift+Q).** Collect emails, or several copies of one, and send them together.
  - **In the composer:**
    - **Add to queue** (Ctrl+Shift+Enter).
    - **Copies** (1–50).
    - **Separate copy per recipient**, so each person gets their own email.
  - **In the queue:**
    - edit any item in the composer, duplicate, set copies, split into one copy per recipient;
    - change the sender, reorder, skip/include, remove;
    - **Send all** or **Send selected**, with a pause between emails, an option to stop at the first failure, and a
      Stop button.
  - **When something fails:** failed items stay queued with their error. What was already sent is never sent again.
  - **Storage:** the queue is encrypted on disk (`outbox.dcx`) and survives restarts.
- **Add-ons, with the same encrypted structure as ServerManagement.**
  - **Sandbox:** program add-ons run at Low integrity in a Job, with a locked-down process.
  - **Encrypted bridge:** ECDH P-256 key exchange, then AES-256-GCM with fresh keys for every run. A plain-text or
    altered line ends the run.
  - **Approval:** you see the publisher, the package's SHA-256, the signature and each permission's risk. Only ticked
    permissions are granted.
  - **Integrity:** files are hash-checked before every run. Updates can't gain permissions, and downgrades are
    refused.
  - **Themes:** theme add-ons are encrypted on disk.
  - **What add-ons can do:** masked addresses, mail, the queue, sending and routing. Every change or send is shown to
    you to allow or deny.
  - **Where to find them:** ◇ Add-ons in the header, and Settings → Add-ons.
  - **Docs and samples:** the SDK and docs are in `samples/addons` and `docs/ADDONS.md`. There are two sample
    packages: the Masked address report and the Midnight blue theme.
- **Uninstall:** "delete data" now also removes the add-ons' own data folders.
- **Self-test: 35 checks.** It now covers the queue and settings search, plus real sandboxed add-on runs (Low
  integrity, a process other programs can't open, profile writes blocked, the encrypted bridge, tampering, permissions
  and approvals).
