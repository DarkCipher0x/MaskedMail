# DarkCipher MaskedMail 0.3.2 (2026-10-21)

- **Screenshots everywhere they're shown:** the README (and the GitHub page) now has the logo and a screenshot gallery:
  the main window in both themes, throwaways, the composer, the queue, the new-address form, sign-in and Settings.
  `build.ps1` refreshes them from each release's own self-test renders (`docs\screenshots\`), so they always show the
  version you download, with demo data only.
- **Better renders:**
  - the message viewer and the editor are now in the pictures (WebView2 draws in a window of its own, so the self-test
    pastes in WebView2's own capture);
  - small windows (new address, sign-in, the throwaway inbox, the queue) are no longer cut off at the right edge.
- **README** restyled to match ServerManagement's: logo, badges, highlights and the gallery. The version badge follows
  the version automatically.
- No change to the app itself since 0.3.1 other than the self-test.
