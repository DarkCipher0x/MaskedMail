# DarkCipher MaskedMail 0.3.1 (2026-10-21)

- **Fixed:** when Fastmail (or another service) took longer than a minute to answer, "Something went wrong" showed
  .NET's own wording ("The request was canceled due to the configured HttpClient.Timeout…"). It now says which service
  didn't answer in time, and the screen that asked shows it like any other error. Every HTTP call in the app goes
  through the same time-limit handling, and a unit test covers it (128 tests).
- **Source code:** each release folder now also has `DarkCipherMaskedMail-<version>-source.zip`, the source the release
  was built from. Before it's written, every file is scanned for local paths, private e-mail addresses, keys and
  private names, and the build stops on a hit (`tools\write-public-source.ps1`).
