# DarkCipher MaskedMail 0.1.9 (2026-10-20)

- **Fixed:** creating a throwaway could show "OpenClipboard Failed (0x800401D0 CLIPBRD_E_CANT_OPEN)", and the live
  inbox didn't open.
  - **Cause:** Windows refuses clipboard access while another program has the clipboard open (a clipboard manager,
    Windows clipboard history, Remote Desktop or a password manager), and the app gave up on the first try. The
    throwaway itself was created.
  - **Now:**
    - The live inbox opens first.
    - Every copy in the app retries for about a second. That covers the address, codes and links, the copy buttons
      and the recovery codes.
    - A clipboard that stays busy only shows a note ("use ⧉ Copy"), never an error that stops what you were doing.
- **Self-test:** 50 checks, with a new one for a busy clipboard. It's simulated, so the test never touches your real
  clipboard.
