# DarkCipher MaskedMail 0.1.8 (2026-10-20)

- **Microsoft Store (MSIX) edition prepared.** It is not submitted yet; the Partner Center steps are in
  `installer\msix\STORE-SUBMISSION.md`.
  - **Packaging:** `tools\make-msix.ps1` packs the same binaries as the MSI. The Store signs the package for free, so
    there is no SmartScreen warning. `-Check` validates the package, and `-TestSign` makes a local test copy.
  - **Data:** a Store install shares the encrypted data folder with the MSI, and uninstalling it never deletes your
    keys.
  - **Start with Windows:** in a Store install this is a Windows startup task (Task Manager → Startup apps), and it
    still starts in the tray. The taskbar identity comes from the package.
  - **Every build** now validates the MSIX. Once the Store identity is filled in, it writes the Store package.
- **Store kit in every release.** `dist\<version>\store\` holds the submission guide (listing text, keywords,
  capability justifications, certification notes), the privacy policy and four Store-size screenshots (demo data).
- **New documents:**
  - **Privacy policy** (`docs\PRIVACY.md`): what is stored, what is sent and to whom, and your choices. The Store
    requires one.
  - **Changelog** (`docs\CHANGELOG.md`): generated from the release notes by every build.
- **Docs refreshed:**
  - README, user guide (installing and uninstalling the Store edition), security model (Store edition), architecture
    (packaging, distribution channels, throwaways, release process) and testing (packaging checks).
  - Every release folder ships them all.
- **Build:** stops if the release notes are missing or a Store screenshot is too small. The main-window renders are now
  1600×960 and include one with a throwaway selected.
- **Self-test:** 49 checks, all passing.
